# Projeto Android

É uma página web que conta um pouco da história do sistema android. Quem criou? O que significam as siglas de atualização? Você pode ver isso nesse pequeno site!

## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

- [HTML5](https://exemplo.com)
- [CSS3](https://exemplo.com)

## 📂 Estrutura do Projeto

A sua estrutura está dividida em 3 pastas e um index.html para conter o conteúdo html. A pasta estilo, contém o arquivo style.css que serve para deixar tudo mais agradavel aos olhos. A pasta fontes contém as fontes que foram utilizadas e a pastas imagens, contém imagens.
